# そもそもパワーストラクチャとは何か

パワーストラクチャとは、**自社と取引先それぞれの人員構成を一覧にし、人と人との関係性を書き込んだもの**。「誰が決裁権を持っているのか」「誰と誰がつながっているのか」「どこに関係の空白があるのか」をひと目で把握できる。

## 何がわかるか

| 項目 | 説明 |
|---|---|
| 決裁権の所在 | 誰の承認・合意で案件が進むかがわかる |
| つながりの有無 | 自社・取引先の誰と誰に接点があるかがわかる |
| 関係の空白 | 接点がない相手、関係が弱い相手が一目で見える |

案件が進まない原因は、技術や価格ではなく**関係性の偏りや抜け**にあることが少なくない。それを見える形にするための表。

## 具体例

自社を左列、取引先を右列に置き、**同じ階層を同じ行**に並べる。上下は各社内での役職の重さ（責任の度合い）を表すだけで、自社と取引先のどちらが上ということではない。

| 階層 | 自社 | 自社内の関係 | 取引先 | 取引先内の関係 |
|---|---|---|---|---|
| 最上位 | 代表取締役 | ― | 代表取締役 | ― |
| | 取締役 | 〇（代表取締役と） | 取締役 | 〇（代表取締役と） |
| | 部長 | △（取締役と） | 部長・決裁者 | △（取締役と） |
| | マネージャ | 〇（部長と） | マネージャ・窓口 | 〇（部長と） |
| | PM | 〇（マネージャと） | 担当者 | 〇（マネージャと） |
| | PL | 〇（PMと） | ― | ― |
| 最下位 | メンバー | △（PLと） | ― | ― |

自社と取引先をまたぐ関係は、階層がずれることも多いので別の表にする。

| 自社 | 取引先 | 関係 |
|---|---|---|
| PM | マネージャ・窓口 | 〇 |
| PM | 部長・決裁者 | △ |
| PL | 担当者 | 〇 |
| メンバー | マネージャ・窓口 | × |

この2つの表からは、「自社の取締役-部長間の情報伝達に△の課題がある」「取引先の決裁者（部長）との関係がPMひとりに依存している」「自社メンバーと取引先窓口担当の意思疎通に課題がある」といったことが、社内・社外の両方について読み取れる。
