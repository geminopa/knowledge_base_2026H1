# 手動テストのエビデンス取得を効率化する方法

手動テストのキャプチャ取得は地味に時間を食う作業。ちょっとした工夫で積み重なると差が出る。

- **ファイル名にテストケースIDを機械的に含める**
  `TC012_正常系_ログイン成功.png` のように、テストケースNoをプレフィックスにしておくとテスト仕様書との突き合わせが一瞬で終わる。あとから「どの画面のキャプチャか」を推測する手間がなくなる。
- **フォルダを画面単位ではなくテスト実施日単位で分けない**
  日付単位で分けると、後から「このケースのエビデンスどこ？」を探す時に日付を覚えていないと詰む。テストケース単位・機能単位のフォルダ構成にする。
- **一連の操作フローは動画キャプチャにする**
  画面遷移を伴う複雑なフローは、静止画を何枚も撮るより画面録画1本の方が早く、かつ「操作した証跡」として説得力もある。
- **ショートカットを覚える**
  範囲指定スクリーンショットのショートカット（Win: `Win+Shift+S` / Mac: `Cmd+Shift+4`）を使うと、都度アプリを立ち上げるより圧倒的に速い。

エビデンスは「後で自分が見返す」だけでなく「他人が検証する」ためのものなので、命名規則を決めてチームで揃えておくと更に効果が出る。
