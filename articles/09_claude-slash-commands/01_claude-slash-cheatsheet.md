# Claude Codeのスラッシュコマンド早見表（まず覚えたい10個）

Claude Codeの入力欄で `/` から始めて入力すると、会話とは別に「操作」を実行できる。全部を覚える必要はなく、よく使うものだけ押さえておけば十分。

## まず覚えたい10個

| コマンド | 何をするか | 使う場面の例 |
|---|---|---|
| `/help` | ヘルプと使えるコマンドの一覧を表示する | コマンド名を忘れたとき |
| `/clear` | 会話をリセットして新しく始める | 別のタスクに切り替えるとき |
| `/compact` | これまでの会話を要約して、コンテキストの空きを増やす | 長いやり取りの途中で、流れを保ったまま続けたいとき |
| `/context` | コンテキストの使用状況を表示する | 「最近回答の精度が落ちてきた」と感じたとき |
| `/resume` | 過去の会話を選んで再開する | 昨日の作業の続きをするとき |
| `/init` | プロジェクト用の `CLAUDE.md` を自動で作る | 新しいリポジトリで使い始めるとき |
| `/memory` | `CLAUDE.md` を編集する | 「毎回言っていること」を覚えさせたいとき |
| `/model` | 使うモデルを切り替える | 重い調査は高性能モデル、軽い作業は高速モデルにするとき |
| `/permissions` | ツールの許可・拒否ルールを管理する | 毎回同じ確認が出てわずらわしいとき |
| `/code-review` | 現在の差分をレビューする（別名 `/review`） | PRを出す前の一次チェック |

## 具体例: よくある1日の流れ

```text
/resume                 ← 昨日の続きを選んで再開
（作業）
/compact テスト方針の話を中心に残して   ← 長くなったので要約
（作業）
/code-review            ← コミット前にセルフチェック
/clear                  ← 次のタスクへ
```

## 補足

- `/` を入力すると候補が一覧表示されるため、先頭の数文字を打って選ぶだけでよい
- コマンドはバージョンアップで追加・変更される。記事の内容が古いと感じたら `/help` で確認する（本記事は2026年9月時点の公式ドキュメントで確認）
- 各コマンドの詳しい使い方は、同シリーズの個別記事を参照
