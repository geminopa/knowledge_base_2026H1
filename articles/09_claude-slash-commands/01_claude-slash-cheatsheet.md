# Claude Codeのスラッシュコマンド早見表（まず覚えたい10個）

Claude Codeの入力欄で `/` から始めて入力すると、会話とは別に「操作」を実行できる。全部を覚える必要はなく、よく使うものだけ押さえておけば十分。

## まず覚えたい10個

| コマンド | 何をするか | 使う場面の例 | 使い方・入力例 |
|---|---|---|---|
| `/help` | ヘルプと使えるコマンドの一覧を表示する | コマンド名を忘れたとき | `/help` だけ |
| `/clear` | 会話をリセットして新しく始める | 別のタスクに切り替えるとき | `/clear`（名前を付けるなら `/clear 会員検索の実装`。`/resume` の一覧で見分けやすくなる） |
| `/compact` | これまでの会話を要約して、コンテキストの空きを増やす | 長いやり取りの途中で、流れを保ったまま続けたいとき | `/compact`（要約の重点を指定するなら `/compact データベース変更を中心に残して`） |
| `/context` | コンテキストの使用状況を表示する | 「最近回答の精度が落ちてきた」と感じたとき | `/context`（内訳を全部見るなら `/context all`） |
| `/resume` | 過去の会話を選んで再開する | 昨日の作業の続きをするとき | `/resume`（一覧から選ぶ。名前が分かっていれば `/resume 名前`） |
| `/init` | プロジェクト用の `CLAUDE.md` を自動で作る | 新しいリポジトリで使い始めるとき | `/init` だけ。作られた `CLAUDE.md` は自分で見直して直す |
| `/memory` | `CLAUDE.md` を編集する | 「毎回言っていること」を覚えさせたいとき | `/memory` で管理画面を開き、編集する `CLAUDE.md` を選ぶ |
| `/model` | 使うモデルを切り替える | 重い調査は高性能モデル、軽い作業は高速モデルにするとき | `/model`（一覧から選ぶ。今のセッションだけ変えるなら選択画面で `s` キー）、または `/model opus` のように名前を指定。選んだモデルは新しいセッションの標準にも保存される |
| `/permissions` | ツールの許可・拒否ルールを管理する | 毎回同じ確認が出てわずらわしいとき | 下の「`/permissions` でルールを追加する」を参照 |
| `/code-review` | 現在の差分をレビューする（別名 `/review`） | PRを出す前の一次チェック | `/code-review`（差分全体）、`/code-review high 1234`（PR #1234 を高い精度で）、`--fix` を付けると指摘を修正まで行う |

## `/permissions` でルールを追加する

`/permissions` を実行すると、今あるルールが「どの設定ファイル由来か」つきで一覧表示される。ここでルールの追加・削除ができる。追加するときは、次の3点を決める。

| 決めること | 内容 | 例 |
|---|---|---|
| 種類 | `allow`（確認なしで実行）/ `ask`（毎回確認）/ `deny`（実行させない） | テストは `allow`、pushは `deny` |
| ルール | `ツール名(条件)` の形で書く。`*` は「何が来てもよい」 | `Bash(./vendor/bin/phpunit *)`、`Read(./.env)` |
| 保存先 | どの設定ファイルに保存するか。追加したルールは、選んだファイルの範囲に効く | 自分だけなら `.claude/settings.local.json` |

- 評価順は **deny → ask → allow**。denyに当てはまるものは、allowに書いてあっても実行されない
- 画面を開いたまま追加・削除しても、Claudeが作業中なら、次のツール呼び出しから反映される
- 具体的なルールの選び方と、設定ファイルへの直接の書き方は [/permissions の記事](06_claude-permissions.md) を参照

## 具体例: よくある1日の流れ

```text
/resume                 ← 昨日の続きを選んで再開
（作業）
/compact テスト方針の話を中心に残して   ← 長くなったので要約
（作業）
/code-review            ← コミット前にセルフチェック
/clear                  ← 次のタスクへ
```

## 補足

- `/` を入力すると候補が一覧表示されるため、先頭の数文字を打って選ぶだけでよい
- コマンドはバージョンアップで追加・変更される。記事の内容が古いと感じたら `/help` で確認する（本記事は2026年9月時点の公式ドキュメントで確認）
- 各コマンドの詳しい使い方は、同シリーズの個別記事を参照
