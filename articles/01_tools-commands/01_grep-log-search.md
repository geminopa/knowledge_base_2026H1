# grepで大量ログから特定パターンを高速検索する

障害調査で数万行〜数十万行のログを目視で追うのは非現実的。grepのオプションを組み合わせると、原因箇所への到達がぐっと早くなる。

- `grep -n "ERROR" app.log` … 行番号付きで検索。該当行がログのどのあたりかすぐ分かる。
- `grep -A 5 -B 2 "Exception"` … 該当行の前後（Before/After）も一緒に表示。前後の文脈が命の障害調査で必須。
- `grep -i "timeout"` … 大文字小文字を無視。ログの表記揺れ対策。
- `grep -rl "user_id=12345" ./logs/` … 複数ファイルから該当ファイルだけを一覧表示（`-l`）。まず対象ファイルを絞り込むときに便利。
- 圧縮済みログ（`.gz`）はそのまま解凍せず `zgrep` を使うと一手間省ける。

ポイントは「まず`-l`でファイルを絞る→次に`-n -A -B`で内容を読む」の2段階に分けること。いきなり全文検索するより体感速度が全然違う。
