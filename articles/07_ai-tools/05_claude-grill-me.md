# Claude Codeに実装前に質問攻めにしてもらう（/grill-me）

「作って」と頼む前に、AIから質問してもらって曖昧な点を潰す手法を **grilling（グリリング）** と呼ぶ。Matt Pocock氏が公開しているSkill `/grill-me` で実行できる（Claude Code標準機能ではなく、別途インストールが必要）。

## 通常の依頼との違い

| | 通常の依頼 | `/grill-me` |
|---|---|---|
| 未決事項の扱い | AIが推測で埋めて実装を進める | AIが質問として洗い出し、ユーザーが決める |
| 質問の出し方 | なし | 判断の依存関係に沿って、答えられるものからまとめて聞く |
| 手戻り | 出来上がってから「違う」と気づく | 実装前に食い違いを解消できる |

## 仕組み

- 決めるべきことを「決める順番」に整理する。たとえば「検索条件はANDかOR」が決まらないと「0件のときの表示」も決められない。このように、先に決めるべきことと、その答え次第で決まることのつながりを整理する（原典ではこれを「設計ツリー」と呼んでいる）
- そのうち、**今の時点で答えられる質問**（先に決めることが済んでいるもの）を1ラウンドにまとめて出す（質問ごとに番号と、AIのおすすめ回答つき）
- 回答すると次に聞ける質問が増え、次のラウンドへ進む
- ファイルの中身など**調べれば分かる事実はAIが自分で調べる**。ユーザーに聞くのは「判断」だけ
- 聞くことがなくなり、ユーザーが「認識が揃った」と確認するまで実装に入らない

## 使い方

インストール（Claude Code内で実行）:

```
/plugin install mattpocock-skills
```

呼び出し（引数として計画を渡す）:

```
/grill-me 会員一覧に検索機能を追加したい。PHP + MySQLの既存システム
```

質問の例（実際の出力は状況によって変わる）:

```
❓ Q1 - 検索条件の結合: 複数条件を入力したとき、AND / OR のどちらで絞り込みますか？
➡️ AND（一般的な検索画面の挙動のため）

❓ Q2 - 0件のとき: 「該当なし」の表示だけでよいですか？
➡️ 表示のみ。条件のリセットボタンは今回のスコープ外
```

## 注意点・コツ

- **`/grill-me` は入口で、実体は `grilling` というSkill。** `/grill-me` は `grilling` を呼び出すだけの薄いラッパー。「grill me」などの言い回しで会話中に自動で呼ばれることもある
- **「1問ずつ聞く」版の解説も出回っているが、現行の定義はラウンドごとに複数質問。** 古い版や第三者の改変版の説明が混ざっているので、挙動は手元で確認する
- **長くなりやすい。** 質問が多すぎると感じたら「ここまでで十分」と伝えて打ち切ってよい
- **外部Skillの導入になる。** 業務PCに入れる前に、社内ルールの確認をしておく
- 小さな修正には過剰。「仕様が曖昧な新機能・設計」に絞って使う
